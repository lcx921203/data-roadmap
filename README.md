# DataRoadmap

**From Data Engineering to AI**

DataRoadmap 是一个面向数据工程、数据平台、数据架构与 AI Data Agent 的生产导向学习与面试产品。

它不是“大而全”的技术百科，也不是单纯的八股题库。核心方法是：

- **主项目技术栈深学**：以三个真实项目涉及的技术栈为主。
- **同类技术做横向对比**：非主栈技术重点理解差异、优缺点、适用场景和选型。
- **Production First（生产优先）**：知识正文默认讲真实生产系统如何设计和实现。
- **Project Case（项目案例）**：三个项目只作为真实经验锚点，不虚构大厂规模。
- **Scale Lab（规模化场景）**：独立训练大数据量、高并发、稳定性、故障、成本、系统设计等能力。
- **Real Interview First（真实面试优先）**：题库以真实面经、公开高可信面试资料为来源，不为了“大而全”凭空造题。
- **Prewritten Answers（预制题解）**：V1 不接 AI 实时回答，重点题目提前制作高质量标准题解。

## Content model

```text
Knowledge Base
    │
    ├── Production Pattern
    │
    ├── Project Cases
    │
    ├── Scale Lab
    │
    └── Interview Bank
```

四类内容相互关联，但分别维护：

- `knowledge/`：系统知识与生产实现
- `interviews/`：真实面试题与预制题解
- `scenarios/`：规模化场景、排障题、系统设计题
- `projects/`：三个真实项目案例
