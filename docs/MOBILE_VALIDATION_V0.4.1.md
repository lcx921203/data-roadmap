# Mobile Validation V0.4.1

Viewport baseline:

```text
390 × 844
```

## PASS

### Learn Home
- Roadmap 可以用 Row 承载 12 Stage；
- Continue 是唯一明显内容 Card；
- Bottom Navigation 四项可读；
- 没有 Dashboard 噪音。

### Knowledge Detail
- 主正文 16px；
- 标题、Summary、Quick Navigation 层级清楚；
- Diagram 默认纵向；
- Code 可横向滚动；
- Production 子项可以继续用 Row。

### Interview List
- Question 是视觉主角；
- Evidence 与 Rank 能解释排序；
- Filter Chip 横向滚动，不挤成多行。

### Interview Detail
- Question / Evidence / 30 秒回答在前部可发现；
- Interview / Learn 模式切换不需要复制内容；
- Answer Framework 使用技术结构图，而不是装饰插画。

### Scale Lab
- Constraint 在 Solution 前；
- 规模参数不是积分 / 游戏化；
- 假设场景边界明确。

### Project Case
- Actual / Boundary / Scale Extension 可明显区分；
- 原型阶段不虚构项目事实。
