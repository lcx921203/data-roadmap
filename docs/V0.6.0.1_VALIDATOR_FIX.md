# V0.6.0.1 Validator Fix

## Failure

V0.6.0 was applied to `main` successfully, but GitHub Pages deployment failed during:

```text
npm run validate:content
```

The validator scanned every Markdown file under `content/knowledge/` and attempted to parse all of them as Knowledge documents.

`content/knowledge/README.md` is repository documentation and intentionally has no YAML Front Matter, so validation stopped with:

```text
Error: Front Matter missing: content/knowledge/README.md
```

## Fix

Knowledge content files follow the stable-ID naming convention:

```text
kb-*.md
```

The validator now only scans those files:

```js
.filter((name) => name.startsWith('kb-') && name.endsWith('.md'))
```

Repository documentation such as `README.md` is no longer treated as a Knowledge entity.

## Scope

Only the validator changes. No Iceberg content, UI, routing, Design System, Evidence, or project truthfulness rules are changed.
