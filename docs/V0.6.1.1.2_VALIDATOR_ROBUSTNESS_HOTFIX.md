# V0.6.1.1.2 Validator Robustness Hotfix

The previous deploy failed because the content validator was using exact Chinese
sentences as correctness assertions. The rewritten article kept the same
semantics but used different wording, so CI failed again.

This patch fixes both sides:

1. Row-level Changes now explicitly connects:
   - Data Manifest -> Data Files
   - Delete Manifest -> Delete Files / Deletion Vector Metadata

2. `validate-content.mjs` now validates Manifest correctness semantically:
   - Data / Delete manifests remain separated;
   - one Manifest uses one Partition Spec;
   - Manifest remains immutable.

It no longer requires one exact Chinese sentence to remain unchanged forever.

This keeps correctness validation strong while allowing content wording to be
improved during future knowledge-structure audits.
